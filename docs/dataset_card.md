# Dataset card

No custom project dataset has been collected or provided. The runtime uses a COCO-pretrained
model; the COCO training dataset is not downloaded into this project. Tests use synthetic arrays
and the installed library's public bus image. Synthetic workflow fixtures are in ignored `.cache/`
and must never be used as project accuracy evidence.

Before real training, record: exact classes/order, source/consent/rights, annotation tool and rules,
coverage counts by class/scenario, negative examples, partial/ambiguous-object policy, source/session
groups, duplicate/near-duplicate audit, split proportions/seed, revision and hashes, reviewers,
frozen test policy, storage location and access/redistribution limits.
