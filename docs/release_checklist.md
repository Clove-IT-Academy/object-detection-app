# Release checklist

- [x] Modular source, validated config, model bundle integrity, local-only preview design.
- [x] Focused automated geometry/config/data/lifecycle tests.
- [x] Real CPU still-image inference and exported-model image parity.
- [x] Tested versions and acquisition instructions documented.
- [ ] Confirm final classes, intended scenario, accuracy and performance targets.
- [ ] Supply reviewed representative data with documented rights and independent splits.
- [ ] Complete real fine-tuning, validation selection and frozen final evaluation.
- [ ] Evaluate exported runtime on the representative dataset.
- [ ] Verify actual webcam preview, Q/Esc/native close, controls and disconnect cleanup.
- [ ] Measure full loop and sustained operation on each supported target.
- [ ] Validate release installation independently and check artifact redistribution terms.
- [ ] Assign maintainer, publish measured limitations, and retain verified rollback artifacts.
